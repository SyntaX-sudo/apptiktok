# THXS CONTROL — Legal Website

Static legal pages for THXS CONTROL. Contact: **nan.nascimento.2022@gmail.com**.

## Files
- `index.html`: legal landing page
- `terms.html`: public Terms of Service
- `privacy.html`: public Privacy Policy
- `TERMS.md` and `PRIVACY.md`: Markdown versions
- `style.css`: website styling

## Publish free with GitHub Pages
1. Open https://github.com/SyntaX-sudo/apptiktok and upload **all files in this folder to the repository root** (or merge them into the existing root without deleting your app).
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. Wait for GitHub Pages to publish.

If the repository is public and GitHub Pages is enabled, the URLs should be:

- https://syntax-sudo.github.io/apptiktok/terms.html
- https://syntax-sudo.github.io/apptiktok/privacy.html

These URLs **will not work until you publish and enable Pages**. Check them in a browser before entering them into TikTok Developers.

## Important
These are starter legal templates, **not legal advice**. Review them against the real application behavior, especially login scopes, token storage, logs, data retention, and account deletion. Publishing legal pages does **not** guarantee TikTok app approval. TikTok may additionally request a demo video, verified website, and review.
